## Contributing {#contributing}

We welcome contributions of all kinds. If you spot an issue or have an idea, you can:

1. 🐛 Report bugs  
2. 💡 Propose features  
3. 📝 Improve documentation  
4. 🔧 Submit code  

If you have a better approach in mind, we'd love to hear it.
